# 📡 خريطة تغطية شبكات اليمن

تطبيق ويب يفتح خريطة موقعك الحالي ويعرض عليها **أبراج شبكات الاتصالات اليمنية** (يمن موبايل، يو، سبأفون، واي) مع **نسبة تغطية كل تقنية 2G / 3G / 4G / 5G** بالنسبة المئوية.

مبني بـ **React + TypeScript + Vite + Tailwind CSS + Leaflet**.

## ✨ المميزات

- 📍 تحديد موقعك تلقائياً (GPS) وفتح الخريطة عليه.
- 🗼 عرض أبراج كل الشبكات بألوان مميزة لكل مشغل:
  | المشغل | MNC |
  |---|---|
  | سبأفون SabaFon | 421-01 |
  | يو YOU (MTN سابقاً) | 421-02 |
  | يمن موبايل Yemen Mobile | 421-03 |
  | واي Y Telecom | 421-04 |
- 📶 نسبة تغطية كل تقنية (5G / 4G / 3G / 2G) لكل شبكة مع تقدير قوة الإشارة بـ dBm.
- 🗼 زر «تحديث الأبراج» لإعادة تحميل بيانات المنطقة أو إعادة تحليل الملف/البيانات التقديرية.
- 📡 فحص توفر 4G لكل مشغل، مع أقرب برج 4G ومصدر بياناته وبعده عن النقطة (تصنيف النطاق المحلي تقريبي، وليس حدوداً إدارية).
- 👆 اضغط على أي نقطة في الخريطة لتحليل التغطية فيها.
- 🔵 دوائر نطاق التغطية لكل تقنية.
- 🛰️ خرائط: شوارع / فاتح / قمر صناعي.
- 📱 واجهة عربية متجاوبة مع الجوال.
- 📊 عرض معلومات اتصال جهازك الحالي (نوع الشبكة والسرعة).
- 🏙️ يفتح التطبيق **دائماً على تعز**؛ زر «موقعي» للانتقال لموقعك الفعلي وزر «تعز» للرجوع.
- 🔔 إشعار تحديث داخل التطبيق عند نشر أي تحديث جديد.
- 📴 يعمل بدون إنترنت (انظر الأسفل).
- 🤖 تطبيق أندرويد (APK) عبر Capacitor.

## 🗂️ مصادر البيانات

1. **بيانات تقديرية** (افتراضي): أبراج مولدة بنموذج حتمي لتجربة التطبيق — **ليست مواقع حقيقية**.
2. **OpenCellID API**: مواقع الأبراج الحقيقية من قاعدة البيانات المفتوحة [OpenCellID](https://opencellid.org). سجّل للحصول على مفتاح مجاني ثم أدخله من زر «مصدر البيانات».
3. **ملف OpenCellID**: نزّل ملف اليمن `421.csv.gz` من [صفحة التنزيلات](https://opencellid.org/downloads.php) وارفعه داخل التطبيق (يعمل محلياً بدون إرسال بيانات).

> ⚠️ النسب المئوية **تقديرية** محسوبة بنموذج انتشار إشارة حسب المسافة من الأبراج ونطاق كل تقنية، وليست قياساً ميدانياً. تقنية 5G غير متاحة تجارياً بشكل واسع في اليمن حالياً.

## 🚀 التشغيل محلياً

```bash
npm install
npm run dev
```

لتعيين مفتاح OpenCellID افتراضياً انسخ `.env.example` إلى `.env`:

```bash
VITE_OPENCELLID_KEY=pk.xxxxxxxxxxxxxxxx
```

> تنبيه: أي مفتاح يوضع في `.env` سيظهر في ملفات الموقع المنشور. الأفضل إدخاله من واجهة التطبيق (يُحفظ في متصفحك فقط).

## 🤖 بناء ملف APK (أندرويد)

### الطريقة 1: تلقائياً عبر GitHub Actions (بدون تثبيت أي شيء)
عند كل `push` يبني ملف `.github/workflows/android.yml` ملف APK:
- من تبويب **Actions** ← آخر تشغيل لـ «Build Android APK» ← **Artifacts** ← `shabka-apk-N` (ملف zip بداخله `shabka.apk`).
- عند الدفع إلى `main` يُنشر أيضاً كإصدار في **Releases**، ورابط آخر نسخة مباشرة:
  `https://github.com/MokhtarAlkmaly/Shabka/releases/latest/download/shabka.apk`

ثبّت الملف على الجوال بعد تفعيل «السماح بالتثبيت من مصادر غير معروفة».

### الطريقة 2: محلياً
يتطلب Node 22+، و JDK 21، و Android SDK (أو Android Studio):

```bash
npm install
npm run android:apk      # الناتج: android/app/build/outputs/apk/debug/app-debug.apk
# أو افتح المشروع في Android Studio:
npm run cap:sync && npm run android:open
```

### نسخة release موقّعة (اختياري)
أضف في إعدادات المستودع (Settings → Secrets → Actions):
`ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`
وسيبني الـ workflow ملف `shabka-release.apk` أيضاً.

## 📲 تثبيت الموقع كتطبيق على الجوال (PWA)

الموقع <https://shabka.vercel.app> أصبح **قابلاً للتثبيت** كتطبيق (PWA) — أيقونة على الشاشة الرئيسية، وفتح بملء الشاشة بدون شريط المتصفح، ويعمل بدون إنترنت بعد أول فتح.

| النظام | طريقة التثبيت |
|---|---|
| **أندرويد (كروم)** | زر «تثبيت» في الشريط العلوي، أو قائمة ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية» |
| **آيفون/آيباد (سفاري فقط)** | زر «مشاركة» ⬆️ ← «إضافة إلى الشاشة الرئيسية» ← «إضافة» |
| **حاسوب (كروم/إيدج)** | أيقونة التثبيت في شريط العنوان |

> ⚠️ لا يظهر خيار التثبيت عند فتح الرابط من داخل تطبيق آخر (فيسبوك، واتساب، إنستغرام…) — افتحه في المتصفح مباشرة.

**الملفات المسؤولة:** `public/manifest.json` (الهوية والأيقونات)، `public/sw.js` (Service Worker للتثبيت والعمل بدون إنترنت)، `src/lib/pwa.ts` (التقاط حدث التثبيت)، `src/components/InstallPrompt.tsx` (زر التثبيت ونافذة الإرشادات).

**بديل:** ملف APK الأصلي (انظر الأعلى) — يحتاج تفعيل «التثبيت من مصادر غير معروفة» ويعطي إشعارات تحديث داخل التطبيق.

## 📴 العمل بدون إنترنت

| الميزة | بدون إنترنت؟ |
|---|---|
| واجهة التطبيق والخطوط | ✅ مضمّنة داخل التطبيق |
| تحديد الموقع GPS | ✅ (أبطأ قليلاً في أول تحديد) |
| البيانات التقديرية وحساب نسب التغطية | ✅ |
| ملف OpenCellID `421.csv.gz` | ✅ يُحفظ في الجهاز بعد رفعه مرة واحدة |
| الخريطة (الشوارع/القمر الصناعي) | ⚠️ تظهر فقط المناطق التي تصفحتها سابقاً وأنت متصل (تُحفظ تلقائياً حتى ~8000 بلاطة) |
| OpenCellID API المباشر | ❌ يحتاج إنترنت |

نصيحة: افتح التطبيق وأنت متصل، وتصفّح تعز (والمناطق التي تهمك) بمستويات التكبير التي تحتاجها، وارفع ملف `421.csv.gz` — بعدها يعمل كل شيء بدون إنترنت.

## ▲ النشر على Vercel

1. ادخل [vercel.com/new](https://vercel.com/new) وسجّل بحساب GitHub.
2. اختر المستودع **MokhtarAlkmaly/Shabka** ← **Deploy** (الإعدادات تُقرأ تلقائياً من `vercel.json`).
3. (اختياري) أضف `VITE_OPENCELLID_KEY` في Settings → Environment Variables.

بعدها كل `push` إلى `main` ينشر تلقائياً، وكل فرع/PR يحصل على رابط معاينة.

## 🔔 إشعارات التحديث

| أين | كيف يعمل |
|---|---|
| **الموقع (Vercel)** | يقارن نسخته بملف `/version.json` المنشور عند الفتح وكل 30 دقيقة وعند الرجوع للتبويب → شريط «يوجد تحديث جديد» → إعادة تحميل. |
| **تطبيق أندرويد** | يقرأ آخر إصدار من GitHub Releases (يُنشر تلقائياً عند كل push إلى `main`). |
| ↳ تغيير في الواجهة فقط | «تحديث الآن» ينزّل `bundle.zip` (~300KB) ويطبّقه فوراً داخل التطبيق — يبقى يعمل بدون إنترنت. |
| ↳ تغيير في الجزء الأصلي (إضافات Capacitor، الصلاحيات، الأيقونة...) | «تنزيل» يفتح ملف `shabka.apk` الجديد لتثبيته. |

التطبيق يحدد نوع التحديث تلقائياً ببصمة `nativeHash` المحسوبة وقت البناء (`vite.config.ts`).
إذا فشل تحديث الواجهة في التشغيل يرجع التطبيق تلقائياً للنسخة السابقة.

## 🌐 النشر على GitHub Pages (اختياري)
سير العمل `deploy.yml` أصبح يدوياً فقط (Actions → Deploy to GitHub Pages → Run workflow) بعد الانتقال إلى Vercel.

```bash
git init
git add .
git commit -m "Yemen network coverage map"
git branch -M main
git remote add origin https://github.com/USERNAME/yemen-coverage-map.git
git push -u origin main
```

ثم من إعدادات المستودع: **Settings → Pages → Source: GitHub Actions**.
سيقوم ملف `.github/workflows/deploy.yml` بالبناء والنشر تلقائياً عند كل `push`.

> تحديد الموقع (GPS) يتطلب HTTPS — وهو متوفر تلقائياً في GitHub Pages.

### مقارنة مناطق تعز

قسم «تغطية مناطق تعز» يعرض يمن موبايل ويو في مجموعتين: مدينة تعز (نقطة شارع جمال)، والحوبان وشرعب الرونة (نقطة لكل منطقة). النقاط في `src/data/taiz.ts` تقريبية وقابلة للتعديل، وليست حدوداً إدارية أو مناطق شبكات «شمال/جنوب». زر «تحليل على الخريطة» ينقل الخريطة ويحمّل البيانات وفق المصدر المختار؛ اضغط موقعك الدقيق لتحليله.

- المصدر التجريبي يولّد أبراجاً لكل نقطة، ولا يمثل قياساً فعلياً أو تأكيداً لتوفر الخدمة.
- مصدر CSV يستخدم الأبراج القريبة من كل نقطة من كامل الملف، حتى خارج نطاق الخريطة الحالي.
- OpenCellID يستخدم الأبراج المحمّلة فقط؛ افتح المنطقة على الخريطة لتحميل بياناتها. غياب البيانات لا يعني انعدام التغطية.
- النسب وقراءات dBm محسوبة بنموذج تقديري، وليست قياسات إشارة الهاتف. مقارنة المناطق تعرض 2G و3G و4G دون الادعاء بوجود 5G.

اختبار عرض المقارنة وحالات البيانات الفارغة/الجزئية (بعد `npm ci`):

```bash
./node_modules/.bin/esbuild tests/TaizCoverage.test.tsx --bundle --platform=node --format=esm --packages=external --jsx=automatic --outfile=node_modules/.cache/taiz-test.mjs
node node_modules/.cache/taiz-test.mjs
```

اختبار لوحة التغطية وقسم «هل توجد 4G هنا؟» (بعد `npm ci`):

```bash
./node_modules/.bin/esbuild tests/CoveragePanel.test.tsx --bundle --platform=node --format=esm --packages=external --jsx=automatic --outfile=node_modules/.cache/covpanel-test.mjs
node node_modules/.cache/covpanel-test.mjs
```
